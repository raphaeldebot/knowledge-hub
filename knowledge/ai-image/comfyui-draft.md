# Fiche ComfyUI

## Résumé

Ce document présente des notes de recherche sur l'utilisation de ComfyUI, une interface node-based pour générer des images avec Stable Diffusion. Il couvre les concepts de base, le prompting, la définition des modèles et paramètres importants.

## Ce que je veux retenir

- ComfyUI est un outil permettant de connecter des nodes pour contrôler les étapes de génération d'images.
- Les prompts positifs et négatifs sont utilisés pour diriger la création de l'image.
- Les checkpoints définissent le style général, tandis que les LoRA ajoutent des styles spécifiques.
- Le nombre de steps, le CFG scale et le seed sont des paramètres importants à ajuster.

## Explication

ComfyUI est une interface graphique pour Stable Diffusion qui permet d'interconnecter différents nodes (blocs) pour créer un workflow personnalisé. Les prompts positifs et négatifs servent à définir la direction artistique de l'image générée, les checkpoints définissent le style général du modèle, tandis que les LoRA permettent d'ajouter un style, un personnage ou un concept spécifique.
